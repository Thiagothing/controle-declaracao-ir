# 📊 Agregador de Dados para Imposto de Renda

Este projeto foi desenvolvido como parte do desafio da DIO, com o objetivo de criar uma ferramenta no **Excel** que auxilia na organização das informações essenciais para a declaração de imposto de renda.

## 🚀 Funcionalidades
- Menus de navegação intuitivos
- Validações automáticas de dados
- Links rápidos para facilitar o acesso
- Interface amigável e prática

## 🎯 Objetivo
Facilitar o controle das entradas financeiras e reunir dados de forma eficiente e validada, tornando o processo de declaração mais simples e organizado.

## 🛠️ Tecnologias Utilizadas
- Microsoft Excel
- Recursos avançados de tabelas, validações e menus
- GitHub para documentação e compartilhamento

## 📚 Aprendizados
Durante o desenvolvimento deste projeto, foram aplicados conceitos como:
- Estruturação de processos técnicos
- Documentação clara e organizada
- Uso do GitHub como ferramenta de versionamento e compartilhamento
